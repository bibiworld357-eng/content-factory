═══════════════════════════════════════════════════════════
  ИНСТРУКЦИЯ: Добавление DNA Reference изображения
═══════════════════════════════════════════════════════════

ПРОСТЫЕ ШАГИ:

1. Сохраните загруженное изображение (3 ракурса лица девушки) как:
   
   z:\!_ofm\!_Script\content factory\public\dna-reference.jpg

2. Перезапустите dev сервер:
   
   npm run dev

3. Готово! Теперь при каждой генерации вариации кадра в Nano Banana 2 
   будет отправляться 2 изображения:
   
   ✓ Основное изображение (загруженная сцена)
   ✓ DNA референс лица (для консистентности)

═══════════════════════════════════════════════════════════

КАК ЭТО РАБОТАЕТ:

• Функция loadDnaReferenceImage() автоматически загружает изображение
  из /public/dna-reference.jpg при первом использовании

• Изображение кешируется в памяти для оптимизации

• В API Nano Banana 2 отправляется массив: images: [сцена, DNA_референс]

• Nano Banana использует оба изображения для сохранения черт лица

═══════════════════════════════════════════════════════════

ПРОВЕРКА:

Откройте DevTools → Console и найдите лог:

  [Wavespeed] frame 1 → POST

В объекте должно быть: images: Array(2)
  - images[0]: основная сцена (data:image/...)
  - images[1]: DNA референс (data:image/...)
