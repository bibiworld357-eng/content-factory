# DNA Reference Image Setup

## Инструкция по установке DNA референса

### Шаг 1: Сохраните изображение DNA референса

Сохраните файл `dna-reference.jpg` (изображение с тремя ракурсами лица девушки) в папку:

```
z:\!_ofm\!_Script\content factory\public\dna-reference.jpg
```

### Шаг 2: Проверьте работу

После сохранения файла, приложение автоматически будет отправлять **2 изображения** в Nano Banana 2 Edit API:

1. **Основное изображение** - загруженная пользователем сцена
2. **DNA референс** - лицо девушки для консистентности

### Как это работает

- При каждой генерации вариации кадра в API отправляется массив из 2 изображений
- Первое изображение - это основная сцена (загруженная через Upload Zone)
- Второе изображение - DNA референс лица, загружается автоматически из `/public/dna-reference.jpg`
- Nano Banana 2 использует оба изображения для сохранения консистентности лица девушки

### Формат изображения

- **Поддерживаемые форматы**: JPG, PNG
- **Рекомендуемый размер**: 1024x1024 или больше
- **Имя файла**: должно быть точно `dna-reference.jpg`

### Кеширование

Изображение загружается один раз при первом использовании и кешируется в памяти для оптимизации производительности.

### Проверка в консоли

Откройте DevTools → Console и проверьте лог:

```
[Wavespeed] frame 1 → POST
```

В объекте `images` должно быть 2 элемента:
- `images[0]` - основная сцена
- `images[1]` - DNA референс

## Troubleshooting

Если DNA референс не загружается:
1. Проверьте что файл существует в `public/dna-reference.jpg`
2. Проверьте консоль браузера на ошибки
3. Перезапустите dev сервер: `npm run dev`
